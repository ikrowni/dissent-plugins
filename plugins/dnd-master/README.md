# LanternKeep DM

The LanternKeep Dungeon Master panel: encounters, monsters, NPCs, items, shops, scenes and journals.

## Configuration

No configuration required.

## Permissions

- `storage:server`
- `storage:user`
- `realtime`
- `identity`
- `members:read`
