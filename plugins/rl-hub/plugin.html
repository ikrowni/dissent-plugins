Live Broadcast (optional)

Show a live match view in the hub for everyone on this server while you play. Nothing is installed — the Dissent desktop app reads the match itself, only while Rocket League is running.

Step 1 — turn on Rocket League's Stats API. Open this file in Notepad:

Steam\steamapps\common\rocketleague\TAGame\Config\DefaultStatsAPI.ini

Find PacketSendRate and change it from 0 to 1, then save and fully restart Rocket League — it only reads this file at launch.

[TAGame.MatchStatsExporter_TA]
Port=49123
WebPort=49124
PacketSendRate=1

There is no "enabled" setting — PacketSendRate=0 is off and anything above 0 is on. 1 is plenty: Dissent sends at most one match update per second no matter what you set here, so a higher rate costs you CPU without adding anything to the hub.

Step 2 — turn on broadcasting.
