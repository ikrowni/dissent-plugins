# LanternKeep

A fifth-edition (5e compatible) virtual tabletop: shared maps with walls, doors, fog and lighting, character sheets, and combat.

## Configuration

No configuration required.

## Permissions

- `storage:server`
- `storage:user`
- `realtime`
- `members:read`
- `identity`
